# const -> master: the map from what ships to what is readable.
#
# Nothing can infer this.  A master's minified+renamed text stops matching its
# const the moment it is installed -- that is the point of installing it -- so a
# tool that matched the two by content would work exactly once.  This file is
# the map, and tests/test_consistency.py holds both ends to it: every
# `const LIB_*` in lua.ws must name a master here, and every master here must
# have its const.  A const with no master is library code nobody can read, and
# ten of them were exactly that until this file existed.
#
# A master listed here but with no const is the opposite mistake: the piece is
# written and never shipped.
#
# lib/str_format.lua, lib/gmatch.lua and lib/str_gsub_str.lua are deliberately
# NOT here: they are reference implementations kept for gates that are too big
# or too stateful to load as source (see each file's header for which).
#
# Install one piece:
#   python -u tools/lib/libconst.py lib/<master>.lua <CONST> --install
# Install every piece:
#   python -u tools/lib/installall.py
